🤖 RPA Projects

This repository contains all the Robotic Process Automation (RPA) projects I developed using UiPath Studio.
Each project includes workflow files and supporting assets to explore and run.

⚙️ How to Use

Download or clone the repository

Click the green Code button above → Download ZIP

Or open a terminal and run:

git clone https://github.com/Kebadan-2704/Robotic-Process-Automation---Projects.git


Unzip the file (if you downloaded the ZIP)

Extract it to your preferred folder using any extraction tool (e.g., WinRAR, 7-Zip)

Open in UiPath Studio

Launch UiPath Studio on your system

Go to Open Project (or Start → Open Local Project)

Browse to the extracted folder and open the .xaml or project file inside

Explore the workflows

Review the automation logic, variables, and sequence of steps

Examine the input/output files, assets, or Excel data if included

Run the project using the Run button to see the automation in action

Make edits and save (optional)

Feel free to customize or extend the workflow

Use File → Save As to create a modified version without altering the original

(Optional) Publish or deploy

If you want to go further, you can publish the project or configure it for a robot or orchestrator setup

🧠 Note

Please ensure you have UiPath Studio (Community or Enterprise Edition) installed and updated for best compatibility.
